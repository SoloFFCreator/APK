QUICK START (5 MINUTES)
================================================================================

1. EXTRACT THE PROJECT
   tar -xzf mega-mall-complete.tar.gz
   cd mega-mall

2. OPEN IN ANDROID STUDIO
   - Launch Android Studio
   - File → Open → Select mega-mall directory
   - Wait for Gradle sync (5-10 minutes)

3. CONFIGURE FIREBASE
   - Go to https://console.firebase.google.com
   - Create a new project
   - Register Android app (package: com.megamall)
   - Download google-services.json
   - Place in app/ directory

4. BUILD & RUN
   - Click Build → Make Project
   - Click Run → Run 'app'
   - Select emulator or device
   - App launches!

BUILDING FOR RELEASE
================================================================================

1. CREATE KEYSTORE
   keytool -genkey -v -keystore mega-mall.keystore \
     -keyalg RSA -keysize 2048 -validity 10000 -alias megamall

2. BUILD RELEASE APK
   ./gradlew assembleRelease

3. SIGN THE APK
   jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 \
     -keystore mega-mall.keystore \
     app/build/outputs/apk/release/app-release-unsigned.apk megamall

4. ALIGN THE APK
   zipalign -v 4 app/build/outputs/apk/release/app-release-unsigned.apk \
     MegaMall-v1.0.apk

TROUBLESHOOTING
================================================================================

Build fails?
  → Update Android Studio and Gradle
  → Run: ./gradlew clean build

Firebase not working?
  → Ensure google-services.json is in app/ directory
  → Verify Firebase project is configured

App crashes?
  → Check Logcat in Android Studio
  → Verify internet connection
  → Check Firebase credentials
